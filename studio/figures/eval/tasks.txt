% Ntex Figures, Ask-box evaluation tasks. Hand-editable.
%
% Each task:
%   === <id> <kind>            kind: cd | blob | ngon | cayley | tidy
%   --- ask                    the instruction, as the author would type it
%   --- source                 the .fig file before (may be empty)
%   --- expect                 one check per line, against the PARSED answer
%   --- touch                  what the instruction may change (comma list);
%                              everything else in the source must come back
%                              unchanged and in order. Names (nodes, blobs,
%                              ngons, cayleys), arrow pairs `A->B` (either
%                              direction), `text`, `globals`, or `*`.
%
% Checks (see src/main.rs, `check`):
%   node N [label=L] [cell=x,y] [cell~x,y (or unplaced)] [color=c]
%   arrow A->B | A--B (either way) | *->B [label=L|none] [head=H] [line=L]
%         [bend] [bend=left|right|0] [loop] [swap] [iso] [thick] [color=c] [pos=NearEnd]
%         (bare `bend` is either side; left/right are relative to the arrow's direction)
%   no node N | no arrow A->B | no blob N
%   count arrows=N | nodes>=N | blobs | ngons | cayleys | elements | texts | grids
%   blob N|* [label=] [parent=] [shaded] [color=] [shape=] [has=a,b] [lacks=a,b] [place=Below]
%   ngon N|* [n=] [axes] [noaxes] [axis=1,2.5] [rotation=k] [turn=k] [flip=k] [labels=a,b]
%   cayley N|* [group=Q8] [pres] [gens=a,b] [ngens=2] [rels=3] [layout=Grid] [legend] [nolabels]
%   comment TEXT | text TEXT | globals [spacing=x,y] [size=s] [scale=s]
%   below C A (same column, lower row) | right B A (same row, further right)
%   apart A B (the arrows between A and B curve to different sides, so none
%             overlaps: A->B bend-left with B->A bend-left, not bend-right)
% Alternatives with |, e.g. head=Tail|Hook. Labels compare without spaces,
% $ and braces, after Unicode → LaTeX.

=== pullback cd
--- ask
make this a pullback square, add P in the corner with its two projections
--- source
% fibre product
B -g-> D
C -f-> D
B at 1,0
C at 0,1
D at 1,1
--- expect
node P cell~0,0
arrow P->B
arrow P->C
count arrows=4
count nodes=4
comment fibre product
--- touch
P, P->B, P->C

=== kernel-blob blob
